## Nine selectable styles
Gladiator remains the original gold choreography and default. Blade Strike (jade, alternating side entry/exit and slash flare), Molten Forge (orange, rising embers and heat glow), Arcane Rift (violet, shrinking/summoning with orbiting particles), Thunderstrike (electric blue, descending recoil), Cinematic (rose, soft zoom and dissolve), Shatter (icy cyan, converging text-depth layers and scattering shards), Heartbeat (red, double pulse), Minimal (white, subtle pop/fade without effects). These use one existing overlay, one timer and one shared motion driver with no new textures or permanent loops. Browser blur, full glyph spin and true per-pixel shattering are approximated with native position, scale, alpha and reusable particles. A style preference is account-wide, validated, resettable, searchable, and frozen per sequence; changes cancel an active effect. Reduced motion displays static centered text for all presets. Polestar Theme/Anim.lua inspected again; prior base countdown CI 45583229084 passed. In-game rendering/synchronization still require verification.

## Independent countdown font

Default remains Morpheus; existing Fonts discovery provides built-in and optional LibSharedMedia choices without a second adapter. The scoped choice is saved separately from interface typography. Very wide alternate fonts shrink to fit the original lettering region; original Morpheus size and choreography stay unchanged. Changing font cancels current visual, next preview/duel uses new choice. No new font files or redistribution. Polestar Theme/Theme.lua font scope reviewed. Prior nine-style CI 45584270302 passed. Live rendering remains to be checked.

## Countdown sound packs
Countdown audio is ON by default, independent of visual style and font. Turning off visuals or audio prevents playback; changing sound settings stops any active cue. Single-stage playback uses the existing countdown clock, no additional timers; only 3/2/1 play, never FIGHT or stationary edit sample. Shared grouped ChoiceRow expands/collapses game categories without additional popup engines. Effects is default, with Master, Ambience, Music and Dialog selectable using native PlaySoundFile. BurstFX Core/Audio.lua and Polestar arcade sound and shared menu patterns reviewed. Included original synthesized metallic tick is the built-in default; the optional locally installed DuelsReimagined_CountdownSounds addon supplies the user-provided pack manifest and sound files. Game voice files are not in the public repository absent redistribution permission. Missing pack selection falls back to the built-in cue without erasing preference. No notifications changes. Live channel and audio timing need client verification.
