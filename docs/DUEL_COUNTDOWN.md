## Nine selectable styles
Gladiator remains the original gold choreography and default. Blade Strike (jade, alternating side entry/exit and slash flare), Molten Forge (orange, rising embers and heat glow), Arcane Rift (violet, shrinking/summoning with orbiting particles), Thunderstrike (electric blue, descending recoil), Cinematic (rose, soft zoom and dissolve), Shatter (icy cyan, converging text-depth layers and scattering shards), Heartbeat (red, double pulse), Minimal (white, subtle pop/fade without effects). These use one existing overlay, one timer and one shared motion driver with no new textures or permanent loops. Browser blur, full glyph spin and true per-pixel shattering are approximated with native position, scale, alpha and reusable particles. A style preference is account-wide, validated, resettable, searchable, and frozen per sequence; changes cancel an active effect. Reduced motion displays static centered text for all presets. ## Independent countdown font
Combat Visuals now has a searchable, resettable Countdown font dropdown. Default remains Morpheus; existing Fonts discovery provides built-in and optional LibSharedMedia choices without a second adapter. The scoped choice is saved separately from interface typography. Missing or rejected font files fall back to Morpheus, then explicit Friz Quadrata; stored missing choices remain visible. Countdown glyphs bypass Theme/Style and global automatic font overrides. Very wide alternate fonts shrink to fit the original lettering region; original Morpheus size and choreography stay unchanged. Changing font cancels current visual, next preview/duel uses new choice.
