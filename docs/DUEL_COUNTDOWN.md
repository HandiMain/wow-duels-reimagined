# Duel countdown visuals

Approved animation demo: oversized gold glyph entrance, impact bounce, short hold, fade, expanding ring, localized glow and twelve reused sparks; stronger FIGHT! stage. Uses existing Motion and DuelDetection; independent passive UIParent overlay. The live cue is inferred from the observed localized countdown, never a confirmed combat-start event. ## Nine selectable styles
Gladiator remains the original gold choreography and default. Blade Strike (jade, alternating side entry/exit and slash flare), Molten Forge (orange, rising embers and heat glow), Arcane Rift (violet, shrinking/summoning with orbiting particles), Thunderstrike (electric blue, descending recoil), Cinematic (rose, soft zoom and dissolve), Shatter (icy cyan, converging text-depth layers and scattering shards), Heartbeat (red, double pulse), Minimal (white, subtle pop/fade without effects). These use one existing overlay, one timer and one shared motion driver with no new textures or permanent loops. Browser blur, full glyph spin and true per-pixel shattering are approximated with native position, scale, alpha and reusable particles. A style preference is account-wide, validated, resettable, searchable, and frozen per sequence; changes cancel an active effect. Reduced motion displays static centered text for all presets.
