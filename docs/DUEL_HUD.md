## Intelligent mode and widget-only ranked launch (2026-11-24)
Supersedes earlier Practice wording and entry-point proposal. Two visible choices: Ranked and Unranked. Ordinary Blizzard /duel, unit menu and other native outgoing challenges are always unranked, even with Ranked preferred. Only the widget's explicitly clicked Challenge Ranked action can supply the one-use target-bound ranked origin; native hook consumes it synchronously and duplicate native attempts invalidate it. The recipient can accept through Blizzard's normal popup: no replacement acceptance UI or native command interception. Both compatible clients must agree to R before countdown and confirm complementary results, otherwise no rating. A selected preference is not consent or an actual match type. All production recording/peer gates remain locked.

D1 discovery owner now accepts a bounded optional rank-offer extension containing R/U, season epoch and build fingerprint. No response never proves absence. Widget probes on show/target selection, with one throttled retry for busy discovery, and listens to matching replies and expiry. The most recent requester can receive a rate-limited preference update using its original verified nonce and expiry. There is no permanent idle polling; reselect a target or /duels peer for a new check when evidence expires. Remote compatibility/availability is an advertisement, not proof of rating eligibility. Missing, mismatched, expired or locally restricted evidence disables Ranked. Compatible U permits selecting the preference (prevents both U players becoming permanently stuck), but the effective displayed mode and launch button remain Unranked until both R. If the displayed Ranked becomes unavailable at the click boundary, refuse rather than silently downgrade. Post-invitation agreement still required before countdown; a rapid accept or changed peer preference can result in an unranked native duel. No extra automatic invite, no synthetic accept, and no damage integration in this update.

Legacy saved practice keys, P wire mode and reason tags remain internal for backward compatibility; all Match History presentation merges old Practice into Unranked. Rating capped remains separate. /duels mode unranked is the preferred command (old practice alias preserved); /duels sim unranked works and old practice simulation alias maps to Unranked. Widget timer artwork cleaned, circular portrait masks/rims and full-width rank lines added. Registered HUD with diagnostic resource and UI-root audit. Fix old stale expected agreement/history counts and add actual mocked native-versus-widget origin and preference-update tests. Visual and real protected-action behavior still unverified.
