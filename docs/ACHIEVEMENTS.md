# Duel-only achievement system

Approved visual: standalone Achievements primary page before the War Games separator, gold point plaque, category tabs and synchronized category rail, scrollable stateful cards. No War Games involvement. Initial catalogue: 30 achievements; placement and rank milestones use existing tier rules, Giant Slayer hidden until earned (strictly higher established tier), Living Legend requires peak Grandmaster in three finished seasons. General milestones require observed standard knockout duels; no retreat/unknown wins; unknown and retreats break streaks. Positive-weight matched evidence only for competitive metrics. Points are derived, never rating or network state. Unlocks/dates are derived deterministically from existing durable canonical history and replay, not a second SavedVariables owner. Old records without timestamps show Date unavailable. Disputed peer evidence recomputes achievements rather than retaining false points. Existing live recording/peer gates stay disabled until required verification. Simulation is isolated and never persisted. No notification integration. Existing 8192 record capacity is unchanged; no unsupported unlimited progression promise.

Artwork: approved concept cropped into a 512x512 atlas for the sidebar plaque, trophy, wreath and first four achievement icons; remaining icons reference native WoW textures pending individual custom art. No claim of in-game pixel parity. Reference study: Polestar Core/Unlocks.lua (requirements independent of presentation, event-driven invalidation) and Polestar_Options/UI/Profiles.lua (data-backed reusable cards, refresh only while visible). No reference code copied.

Testing: initial implementation CI 45478809995 passed syntax and all Lua runtime checks including the achievement evidence checks; static checks required the five-button sidebar contract and regenerated competitive fingerprint. Added local-adapter reopen/isolation coverage and mocked page filter/scroll/scope coverage. WoW visual and actual duel recording remain unverified.

Visual-only refinement: custom stable ID-to-slot mapping covers all 30 achievements, five category emblems and hidden state. Existing four approved row crops retained, remaining 26 newly drawn in a shared metal/engraved emblem style. Category tabs and filter rows use custom alpha artwork. Total points use one integrated trophy plaque and each row one seamless alpha medallion, both with live text and subdued silver locked/unavailable states. Primary sidebar now caps plates at 166x68 with proportional shrinking and tighter gaps; War Games remains below its divider. Model geometry allows two further primary pages at 636px rail height without shrinking the new default. No catalogue, points, recording, simulation or notification behavior changes. In-game visual verification required.
