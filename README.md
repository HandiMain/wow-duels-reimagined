# Duels Reimagined ⚔️

**A new way to enjoy duels in World of Warcraft.**

Duels Reimagined is an upcoming in-game companion built around memorable duels, clear results, and a clean interface that feels at home in Azeroth.

We're designing it with **World of Warcraft: Forever** and **Retail** in mind.

**Current status:** In design. There is no playable download yet.

Features and supported game versions will be confirmed as development progresses.
